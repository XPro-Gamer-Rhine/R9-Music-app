# R9 Music — the audiophile player for iPhone, iPad & Android

A native high-res music player with the full **R9-EQ engine** inside: 10-band
EQ, PRO parametric mode, the Virtual Driver IEM builder (1,088 real IEMs),
community song presets, playlists, living fluid artwork and a real FFT
visualizer.

**Website:** https://xpro-gamer-rhine.github.io/R9-Music-app/

## Android — download

[**Downloads**](https://github.com/XPro-Gamer-Rhine/R9-Music-app/releases)
· Android 9 and newer · free, no account, no telemetry.

| File | For |
|---|---|
| `R9Music-<version>-arm64-v8a.apk` | Almost every phone made since 2017 — start here |
| `R9Music-<version>-armeabi-v7a.apk` | Older 32-bit devices |
| `R9Music-<version>-universal.apk` | Works everywhere, larger download |

Verify with `SHA256SUMS.txt` if you like. Every build is signed with the same
key, so updates install over the top and keep your library and profiles.

Android's own audio equalizer is device-dependent and usually five fixed bands,
so R9 Music does not use it: the Android build ships its own C++ DSP engine on
AAudio, a port of the same filter maths the macOS R9-EQ app runs.
